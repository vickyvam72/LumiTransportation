## ✦ Lumi Transportation v2.6

**Unduh:** `LumiTransportation-v2.6.apk` di bagian *Assets* di bawah. Pasang di atas versi lama, data tetap aman.

### ✨ Baru
- Tombol **Bersihkan** di hasil pencarian: mengosongkan asal, tujuan, dan hasil, lalu kembali ke beranda

### 🚌 Posisi bus lewat aplikasi TJ
- Server armada Transjakarta hanya melayani aplikasi resminya, jadi fitur posisi bus di dalam Lumi dihapus (*Bus di sekitarmu*, posisi bus di info rute, dan koneksi ke server armada)
- Di setiap ruas Transjakarta, Mikrotrans, dan Royaltrans ada tombol **Lihat posisi bus di aplikasi TJ**: membuka aplikasi TJ, atau Play Store bila belum terpasang

---

### 🇬🇧 English
- New **Clear** button on results to reset origin, destination and results and return home
- In-app live bus positions removed (the fleet server only serves the official app); each bus leg now has a **See bus position in the TJ app** button that opens the TJ app or the Play Store
