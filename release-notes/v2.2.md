## ✦ Lumi Transportation v2.2

**Unduh:** `LumiTransportation-v2.2.apk` di bagian *Assets* di bawah. Pasang di atas versi lama, data tetap aman.

### 🐞 Perbaikan
- **Bus langsung**: koneksi ke data armada sekarang lewat koneksi native Android (sebelumnya lewat WebView yang tidak bisa tersambung). Bila tetap gagal, Lumi menampilkan penyebabnya dan tombol **Lihat di aplikasi TJ**
- **Arah & varian dari GTFS resmi**: data resmi sering menyimpan perjalanan pulang-pergi sebagai satu pola memutar (184 dari 240 rute). Pola ini kini dipecah di titik balik, lalu dipilih dua arah utama; pola lain menjadi varian berketerangan (mis. 9: Pluit ⇄ Pinang Ranti + varian via Tol; JAK36: PGC ⇄ Cilangkap)

### ⚡ Peningkatan
- **Pencarian rute 3–7× lebih cepat** dengan data resmi (A*, graf array bertipe), mis. Pancoran → PIK 2 dari ±6 detik menjadi <1 detik
- Pemantau perubahan rute di GitHub Actions kini aktif dan mencatat statusnya; ringkasan GTFS resmi tersedia di cabang `gtfs-data`

---

### 🇬🇧 English
- **Live buses** now connect through a native Android connection; on failure Lumi shows the reason and an **Open TJ app** button
- Loop-shaped official GTFS patterns are split into two clear directions with described variants
- Route search 3–7× faster with official data; the route-change watcher on GitHub Actions is now running
