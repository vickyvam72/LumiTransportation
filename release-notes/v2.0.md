## ✦ Lumi Transportation v2.0

**Unduh:** `LumiTransportation-v2.0.apk` di bagian *Assets* di bawah. Pasang di atas versi lama, data tetap aman.

### ✨ Baru
- **Bagikan rute sebagai gambar**: tombol *Bagikan rute* di setiap kartu hasil dan di detail perjalanan, hasilnya gambar PNG lengkap dengan jam naik, arah, tempat turun, dan tarif
- **Layar sambutan & "Satu langkah lagi"**: dua layar singkat yang muat dalam satu layar tanpa scroll, untuk izin lokasi, notifikasi, berjalan di latar belakang, dan "Mulai otomatis" (Xiaomi, Oppo, Vivo, Realme, Infinix)
- **Perubahan rute terdeteksi tiap jam**: GitHub Actions memeriksa GTFS resmi Transjakarta tiap jam, dan aplikasi mengecek umpan perubahan serta versi file GTFS tiap jam, lalu memberi notifikasi
- **Mode pendampingan GPS**, **filter moda & urutan**, **tema biru muda** dan logo baru (dari v1.8)
